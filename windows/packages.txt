# --- C/C++, and the compiler treesitter needs for its parsers ----------------
# LLVM.LLVM gives clangd and clang-format, but NOT a usable compiler: the
# standalone Windows build ships no C runtime headers, so treesitter parsers
# fail at `fatal error: 'stdlib.h' file not found`. llvm-mingw carries UCRT
# headers and is what actually builds them -- see platform.ts_compilers().
LLVM.LLVM                        # clangd + clang-format only
MartinStorsjo.LLVM-MinGW.UCRT    # the C compiler treesitter needs
